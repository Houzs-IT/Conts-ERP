# System-type bugs from Houzs and Hookka, checked in Conts (11 Oct 2026)

Scope: correctness bugs in how the system is built (time, money, concurrency, transactions, failures, input and output
safety), not single screens, not speed, not permissions. Sources, read-only: Houzs `origin/main` (check scripts,
`docs/bugs/`, fix commits), Hookka `docs/BUG-CLASSES.md` (`Cnn`) and `docs/BUG-HISTORY.md` (`BUG-…`), and the ticket
study (`HZ-nn`, `HK-nn`).

How each verdict was reached: the Conts code was read (paths below), then the bug was provoked on a local server with
the real-size data (139 units, 4,288 bookings, 3,441 guests). `scripts/api-checks/system-correctness.mjs` is the proof:
**14 of its checks fail on `main` and all 34 pass on this branch** (run against the same database, same server).

Verdicts: **present** (fixed in this PR), **partly** (fixed where it matters, or left with a reason), **not present**.
